# C++ practice and exercises

Small console programs written while learning C++ (a mix of COSC 1337 course labs and personal practice).
Each file is a standalone program with a `main()`; compile one at a time, e.g. `g++ DL5_L2_Parker.cpp -o diamond && ./diamond`.

| File | What it does |
| --- | --- |
| `DL5_L1_Parker.cpp` | Menu-driven calculator: restaurant bill (8.25% tax + tip) and BMI. |
| `DL5_L2_Parker.cpp` | Prints an asterisk diamond of a user-chosen size; repeats until 0 or less is entered. |
| `DL5_L3_Parker.cpp` | Endless random addition quiz with a final score report (type a negative number to quit). |
| `DL5_L4_Parker.cpp` | Calculates how long sound takes to travel a distance through air, water, or steel. |
| `basic_trig.cpp` | Converts degrees to radians and computes sin(36°) + cos(72°). |
| `cowboys_star_players.cpp` | Prints an aligned table of players using `setw` / `left`. |
| `rounding_numbers.cpp` | Demonstrates `setw`, `setprecision`, `fixed`, `showpoint` formatting. |
| `deleteme.cpp` | Empty placeholder program. |

Every source file has a detailed explanatory comment at the top and inline comments describing each step.
